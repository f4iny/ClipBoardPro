# Glossary

### Clipboard Item
A discrete entry captured from the system clipboard, containing either plain text, source code, or image data, along with capture metadata.

### Working Set
The set of physical memory pages currently allocated to a process in RAM by the operating system.

### Working Set Trimming
An operating system operation where inactive physical memory pages of a process are flushed to standby or pagefile storage when the process enters a dormant state.

### Debounce
A timing mechanism that delays the processing of rapidly arriving events until a specified quiet period has elapsed, discarding redundant intermediate triggers.

### Media Cache
A dedicated directory on the local filesystem used to store binary image assets outside of web storage quotas.

### Content Visibility
A browser rendering engine optimization that defers layout and painting computations for off-screen elements until they approach the visible viewport.
